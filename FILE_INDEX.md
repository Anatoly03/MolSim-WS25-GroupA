## 📝 File Formats

### Checkpoint Format (`.chkpt`)
```
# MolSim Checkpoint File
# Format: x y z vx vy vz m fx fy fz old_fx old_fy old_fz old_x old_y old_z p_id
# Particle count: N
<x> <y> <z> <vx> <vy> <vz> <m> <fx> <fy> <fz> <old_fx> <old_fy> <old_fz> <old_x> <old_y> <old_z> <p_id>
...
```

### YAML Config Format
```yaml
name: Simulation Name

config:
  delta_time: 0.0005
  total_time: 15
  gravity_force: [0.0, -12.44, 0.0]
  thermostat_interval: 1000
  thermostat_temperature: 0.5
  checkpoint_path: "output/file.chkpt"
  checkpoint_input: "output/file.chkpt"
  # ... other parameters

particles:
  object_name:
    type: cuboid|disc|ball
    # ... object parameters
```
